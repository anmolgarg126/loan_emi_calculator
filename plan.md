# Plan

Build a fully static, lender-neutral Indian home-loan calculator with an optional overdraft (OD) simulation using Vite, React, TypeScript, and plain CSS. Use a deterministic daily event ledger for OD activity, keep financial formulas outside React, and deploy through GitHub Actions to `https://<current-repository-owner>.github.io/loan_emi_calculator/`, with the owner resolved automatically at build time.

## Scope
- In: Fully disbursed loans after EMI commencement; standard monthly-reducing EMI; fixed rates plus rate changes effective on EMI dates; both rate-reset modes with keep-EMI/adjust-tenure as the default; prepayments on EMI dates; optional OD premium, one-time setup fee, annual fee, opening surplus, monthly surplus, and up to 100 arbitrary dated deposits/withdrawals; Actual/365 daily OD interest; drawing-power reduction; regular-versus-OD comparison; amortization; two accessible charts; fragment-based sharing; Print/Save as PDF; CSV; typed `.xlsx`; validation; tests; and GitHub Pages deployment.
- Out: Under-construction disbursements and pre-EMI, exact lender-product replication, live lender rates, tax advice, affordability underwriting, named local scenarios, cloud accounts or sync, backend/database/authentication, analytics, React Router, Next.js, Tailwind, PWA installation, break-even-surplus estimates, custom domains, custom benchmark-index engines, embedded Excel charts, and more than two web charts in v1. Deployment uses a public repository named `loan_emi_calculator`; the owning username is never hardcoded.
